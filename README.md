# Minigame 1
## Devlog

If Unity were a theater production, the relationship between Components, GameObjects, and Scenes would work like this: a Scene is the entire stage for one performance — it contains everything the audience can see in that particular show. The GameObjects are the actors and props standing on that stage: the hero, the tree, the coin, each one a distinct "thing" in the performance. Components are the roles and skills each actor is cast with: the hero might have the "Walker" Component and the "CoinCollector" Component, while the tree might just have a "StandStillAndLookPretty" Component. Just like one actor can play several roles at once, one GameObject carries many Components, and the Scene (the stage) only comes alive because of the cast of GameObjects and what their Components let them do.
